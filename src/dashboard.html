当前线路

域名出口连接缓存年龄

首次访问会学习线路，之后跨浏览器、Git 和下载器复用。

线路健康

域名线路响应估计状态

失败按域名与出口分别冷却；其他域名继续正常访问。网页按连接延迟优先；Release、归档和 Git 独立选路，完整传输超过 4 MiB 后学习吞吐。短片段不参与评分。

优化选项

开关即时生效并保存。分段需强 ETag 和规范 Range；缓存遵守上游指令，跳过 Cookie、认证和签名链接。

最近事件

暂无事件

运行与恢复

当前设备启用后，常见 GitHub 地址会被自动接入。关闭网页不影响加速；托盘可打开面板或停止。Stop.cmd 会恢复系统设置，异常残留可用 Recover.cmd 修复。

已有 HTTP 代理可以在 config.json 配置 upstream 后重新启用，默认无需代理。自带远程代理、独立证书库或固定 IP 的应用可能需要单独接入。

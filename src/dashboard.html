运行与恢复

当前设备启用后，常见 GitHub 地址会被自动接入。关闭网页不影响加速；托盘可打开面板或停止。Stop.cmd 会恢复系统设置，异常残留可用 Recover.cmd 修复。

已有 HTTP 代理可以在 config.json 配置 upstream 后重新启用，默认无需代理。自带远程代理、独立证书库或固定 IP 的应用可能需要单独接入。
